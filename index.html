Frequently Asked Questions

Everything you need to know about running workflows on Zentrix AI.

Which AI model powers Zentrix AI?

Zentrix AI runs on Google's gemini-3.8-flash engine via secure serverless functions, keeping your API keys hidden while delivering fast, structured outputs.

How does Brand Voice work?

Any guidelines you save in the Custom Brand Voice box are automatically injected into every workflow prompt so emails, hooks, and SOPs stay consistent across your team.

Can I export or reuse previous generations?

Yes—every generation is saved in your Recent Workflow History panel for one-click reloading, instant clipboard copy, or `.txt` file download.
